## 2. Six Legacy Order-Flow, VWAP & Relative Strength Defects Rectified in Rust

1. **Intraday Future-Data Lookahead via `YYYY-MM-DD` Date-String Join (`indicator_engine.py:410–456`, `DEF-001`):**
   - Legacy `calculate_relative_strength` joined symbol candles and benchmark candles on calendar date strings (`YYYY-MM-DD`). On intraday `1m`, `5m`, `15m`, or `1h` bars during trading session `T`, every morning candle at `09:15 ICT` (`02:15 UTC`) joined against **Day `T`'s closing `VNINDEX` value** (`15:00 ICT`) — leaking hours of future benchmark price movement into morning indicator and backtest decisions (`DEF-001` violation).
   - **Rust Fix (`src/indicators/relative_strength.rs`):** Aligns strictly on **completed bar-close timestamps** (`bench_close_ts = bench.timestamp + benchmark_tf.seconds() - 1 <= sym_query_ts`), additionally capped by `replay_causal_close_timestamp` during Bar Replay so future benchmark closes are strictly inaccessible.
2. **Holiday Gap `NaN` Poisoning in Rolling Benchmark Returns (`indicator_engine.py:432–448`):**
   - When the benchmark series lacked a quote on a symbol trading day (e.g., cross-market holidays or suspended benchmark dates), legacy code emitted `NaN` and fed it into `pct_change(period)` — wiping out `period + 1` consecutive bars of Relative Strength.
   - **Rust Fix (`src/indicators/relative_strength.rs`):** Uses bounded Last-Observation-Carried-Forward (LOCF) binary search (`partition_point(|&(b_close_ts, _)| b_close_ts <= sym_query_ts)`) capped at `MAX_BENCHMARK_CARRY_SECONDS` (`45 * 86_400` seconds) so market holidays carry forward cleanly with zero `NaN` holes while stale multi-year mismatches return `None`.
3. **Absence of Synchronized Main-Pane Rebased Comparison Overlay (`REA-R11-07`):**
   - Legacy Sumi only returned detached server-side `RS Ratio` values without rendering the benchmark curve directly on the main candlestick chart rebased to the left edge of the visible viewport (`Log`, `Linear`, `%`, and `IndexedTo100` compatible).
   - **Rust Fix (`src/indicators/relative_strength.rs` & `src/chart.rs`):** Computes `compute_rebased_comparison_series(symbol_candles, aligned_benchmark_close, strict_range)` rebasing the aligned benchmark curve to `symbol_candles[anchor_idx].close` and incorporates it into `main_price_scale` autoscale + batched polyline rendering.
4. **Detached `limit: 100` Text Card Instead of On-Chart `VRVP` / `FRVP` (`TechnicalFlowBBViewer.tsx`, `REA-R11-05`, `REA-R11-06`, `REA-R11-08`):**
   - Legacy Sumi displayed only single-bar `daily_pressure` and `coverage_ratio` text readouts in a detached panel capped at `100` HTTP bars, with **zero** price-binned Volume Profile (`VRVP`), interactive `Fixed Range Volume Profile` (`FRVP`), Point of Control (`POC`), or `70%` Value Area (`VAH`/`VAL`).
   - **Rust Fix (`src/indicators/volume_profile.rs`, `src/drawings/`, `src/chart.rs`):** Computes exact overlap-conserving price-binned Volume Profile with intrabar `OHLCV_PROXY` buy/sell volume attribution (`pressure = clamp((2*close - high - low) / (high - low), -1, 1)`), `POC`, CME dual-row `70%` Value Area (`VAH`/`VAL`), `HVN`/`LVN` detection, and single-mesh GPU-batched right-aligned `VRVP` + interactive 2-click `FRVP` drawing tool.
5. **Complete Absence of Exchange-Session `VWAP` (`REA-R11-09`):**
   - Legacy Sumi had neither intraday session-resetting `VWAP` nor multi-asset timezone awareness (`UTC+7` HOSE/VN30F vs `UTC-5` US Equities vs `UTC` Crypto) or variance bands.
   - **Rust Fix (`src/indicators/vwap.rs` & `src/journal/market_rules.rs`):** Adds `ExchangeVenue::session_utc_offset_seconds()` (`+25,200s` VN, `-18,000s` US, `0s` Crypto) and numerically stable one-pass Welford volume-weighted `VWAP` with $\pm 1\sigma$ and $\pm 2\sigma$ bands: resetting at local civil midnight on intraday `1m..4h`, calendar month (`MTD VWAP`) on `1D`, and calendar year (`YTD VWAP`) on `1W`, with clean per-session rendering segments eliminating overnight diagonal bleed.
6. **Complete Absence of Interactive `Anchored VWAP (AVWAP)` Drawing (`REA-R11-09`):**

## 3. Mathematical & Architectural Contracts

All domain modules (`src/indicators/volume_profile.rs`, `src/indicators/vwap.rs`, `src/indicators/relative_strength.rs`, `src/drawings/`) are **100% pure `f64`/`i64` Rust** (`0` new crates in `Cargo.toml`, `wasm32-unknown-unknown` verified).

### 3.1 Order-Flow Volume Profile (`VRVP` & `FRVP`, `src/indicators/volume_profile.rs`)

- **Price Domain `[range_low, range_high]`:** Computed across finite candles in the slice (`high >= low`). If `range_high - range_low <= 1e-12` (flat synthetic/halted slice), padded symmetrically by `pad = min(max(raw_low * 1e-4, 1e-12), raw_low * 0.5)` when `raw_low > 0.0` (preserving strict positive micro-price floors) and `max(|raw_low| * 1e-4, 1e-4)` otherwise. Uniform bin height `bin_height = (range_high - range_low) / row_count` (`row_count` clamped `8..=200`, default `40` for `VRVP`, `24` for `FRVP`).
- **TPO / Zero-Volume Fallback:** If every valid candle in the slice has `volume <= 0.0` (e.g., volume-omitted 5-column `SPY.csv`), falls back to equal weight `1.0` per candle (`uses_tpo_fallback = true`); otherwise uses exact `candle.volume.max(0.0)` (`uses_tpo_fallback = false`).
- **Intrabar Order-Flow Attribution (`OHLCV_PROXY`):**
  $$\text{pressure} = \begin{cases} \mathrm{clamp}\!\left(\frac{2C - H - L}{H - L}, -1, 1\right), & H - L > 10^{-12} \\ +1, & C > O \\ -1, & C < O \\ 0, & C = O \end{cases}, \qquad V_{\text{buy}} = V \cdot \frac{1 + \text{pressure}}{2}, \quad V_{\text{sell}} = V - V_{\text{buy}}$$
- **Conservative Interval-Overlap Binning:** Each bar's `[L, H]` overlaps bins `b0..=b1` in proportion to `overlap_k / sum_k(overlap_k)`, guaranteeing exact conservation:
  $$\sum_{k=0}^{N-1} \text{bin}_k.\text{total\_volume} = \sum_{i} V_i \quad (\text{within IEEE-754 } \le 10^{-9})$$
- **Point of Control (`POC`) & CME Dual-Row `70%` Value Area (`VAH` / `VAL`):**
  - `poc_index`: bin with maximum `total_volume` (tie-break: closest `price_mid` to volume-weighted typical price center, then higher index).
  - Expanding outward from `[lo, hi] = [poc_index, poc_index]` while `acc < target_vol = value_area_pct * total_volume`, compares upward 2-bin sum vs downward 2-bin sum (CME Market Profile convention), advancing into the higher-volume side until `acc >= target_vol`; `val_price = bins[lo].price_low`, `vah_price = bins[hi].price_high`.
  - **High/Low Volume Nodes (`HVN` / `LVN`):** `is_hvn` when `total_volume >= 1.5 * mean_bin_vol`; `is_lvn` when `total_volume > 0.0 && total_volume <= 0.5 * mean_bin_vol`.

### 3.2 Exchange-Session `VWAP` & `Anchored VWAP (AVWAP)` (`src/indicators/vwap.rs`)

- **Session Bucket Key (`utc_offset_seconds` from `ExchangeVenue::session_utc_offset_seconds()`):**
  - Intraday (`1m`, `5m`, `15m`, `1h`, `4h`): computes `local_days = timestamp.saturating_add(utc_offset_seconds).div_euclid(86_400)` and resets whenever `local_days` changes (`00:00 ICT` for VN `HOSE`/`HNX`/`VN30F`, `00:00 EST` for US Equities, `00:00 UTC` for Crypto).
  - Daily (`1D`) & Weekly (`1W`): resolve UTC civil dates directly from `timestamp.div_euclid(86_400)` (`B2`) without adding intraday `utc_offset_seconds`, resetting at calendar month `(year, month)` (`MTD VWAP`) for `1D` and calendar year `year` (`YTD VWAP`) for `1W`.
- **One-Pass Volume-Weighted Welford Mean & Variance (Rescaled for Extreme Magnitudes):**
  $$\text{prev} = \mu, \quad W \mathrel{+}= w_i, \quad \mu \mathrel{+}= \frac{w_i}{W}(tp_i - \text{prev}), \quad M_2 \mathrel{+}= w_i (tp_i - \text{prev})(tp_i - \mu)$$
  $$\sigma = \sqrt{\max\!\left(\frac{M_2}{W},\, 0\right)}, \qquad \text{Upper}_{k} = \mu + m_k \sigma, \quad \text{Lower}_{k} = \mu - m_k \sigma$$
  where $tp_i = (H_i + L_i + C_i)/3$ and $w_i = V_i$ (or equal weight `1.0` when all volumes in the slice are `0.0`). `WelfordVwapAcc` rescales extreme magnitudes (`1e150` / `1e-150` `inv_w_scale` and `dev_scale`) so neither `1e160` prices/volumes overflow nor `1e-160` micro-assets underflow (`B3`), while variance remains non-negative by construction.

### 3.3 `DEF-001` Causal Close-Aligned `Relative Strength` (`src/indicators/relative_strength.rs`)

- For every valid positive benchmark candle `b`, its publicly known causal completion instant is `b_close_ts = b.timestamp + benchmark_tf.seconds() - 1`. Any benchmark bar with `b_close_ts > replay_causal_close_timestamp` is discarded.
- For symbol bar `i`, its causal query instant is `sym_query_ts = min(c.timestamp + symbol_tf.seconds() - 1, replay_causal_close_timestamp)` (or `c.timestamp + symbol_tf.seconds() - 1` outside replay).
- Binary search picks the latest completed benchmark bar with `b_close_ts <= sym_query_ts` (bounded by `sym_query_ts - b_close_ts <= 45 * 86_400` seconds).
- Normalized ratio anchored at the first valid aligned pair `(sym0, bench0)`:
  $$\text{RS}_i = 100.0 \cdot \frac{C_i / C_0}{B_i / B_0}, \qquad \text{RS\_SMA}_i = \frac{1}{P} \sum_{j=i-P+1}^{i} \text{RS}_j$$
- Visible-window Rebased Benchmark Overlay for `strict_range`: anchored at the first valid aligned bar `vis0` inside `strict_range` (`vis0.close * (bench_close[i] / bench_close[vis0])`), preserving exact alignment in `Normal`, `Logarithmic`, `Percentage`, and `IndexedTo100` scales via live viewport-relative `compute_compare_viewport_scale` (`O(1)` over `SeriesBlockIndex::first_valid_index`).
