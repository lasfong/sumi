## 3. Pure Rust Mathematical & Causal Contracts (WASM-Safe `f64`/`i64`/`u64`)

### 3.1. Fail-Closed 2-Level `CustomSignalRuleSpec` & $O(N)$ `PrecomputedCatalogMatrix`
For a causal candle slice $S = [c_0, \dots, c_{N-1}]$, `PrecomputedCatalogMatrix::compute(S)` computes all `17` `SIGNAL_CATALOG` series, `MarketRegime`, `(bullish_count, bearish_count)`, and both `Balanced` & `TrendFocused` composite health scores in $O(N)$ time.
- **Per-Clause Fail-Closed Invariant:** Given clause $q = (\text{id}, P)$ at bar $i$ with compact point $p_{k,i}$:
  $$\text{eval}(q, i) = \begin{cases} \text{false} & \text{if } p_{k,i}.\text{quality} \ne \text{Valid} \\ p_{k,i}.\text{bool\_val} = \text{Some}(b) & \text{if } P = \text{BoolIs}(b) \\ \text{cmp}_{\text{op}}(p_{k,i-1}, p_{k,i}, \theta) & \text{if } P = \text{FloatCmp}(\text{op}, \theta) \\ (\text{mask} \ \& \ \text{bit}(\text{regime}_i)) \ne 0 & \text{if } P = \text{RegimeIn}(\text{mask}) \end{cases}$$
  where `CrossAbove` / `CrossBelow` additionally require $i \ge 1 \land p_{k,i-1}.\text{quality} = \text{Valid}$.
- **Bounded 2-Level Group & Confluence Evaluation:** For directional leg $L$ (`enabled = true`) with groups $G_1, \dots, G_m$ ($1 \le m \le 4$, $1 \le |G_r| \le 8$; empty legs or empty groups fail closed to `false`) and gate $\Gamma$:
  $$\text{eval}(L, i) = (m \ge 1) \land \left(\bigoplus_{r=1}^m \bigodot_{c \in G_r} \text{eval}(c, i)\right) \land \left(\neg \Gamma.\text{enabled} \lor \text{eval}(\Gamma, i)\right)$$
  Signals evaluated at `Close[i]` (`!incomplete_tail_bar`) enqueue `PendingStrategyOrder` for **`Open[i + 1]`** (`EndOfSeriesCutoff` when $i + 1 = N$).

### 3.2. Closed-Bucket `SignalCatalog` / `Confluence` Alerts, Cooldown & Formula-Safe Export
On rule timeframe $\Delta_{\text{rule}}$ over causal base prefix $B[..=i_{\text{end}}]$ (`last_base_close_ts` $= t_{\text{end}} + \Delta_{\text{base}} - 1$):
1. **Closed-Bucket Gate (`DEF-001`):** Bucket $t$ (`bar_open_ts` $= \tau_t$) is eligible iff $\neg \text{is\_bucket\_incomplete\_at\_close}(\tau_t, t_{\text{end}} + \Delta_{\text{base}} - 1, \Delta_{\text{base}}, \Delta_{\text{rule}})$ and its closing base timestamp exceeds `armed_at_timestamp`.
2. **Cooldown Suppression & Rewind Restoration:** For `OncePerBarClose` with `cooldown_bars` $= C \in [0, 500]$, if the previous trigger for rule $r$ occurred at bucket index $t_{\text{prev}}$, bucket $t$ is suppressed whenever $t - t_{\text{prev}} \le C$, and after scanning up to the last closed bucket $t_{\text{last}}$:
   $$\text{cooldown\_remaining\_bars}(r) = \max\!\left(0,\; (t_{\text{prev}} + C + 1) - (t_{\text{last}} + 1)\right)$$
   Because `evaluate_causal` recomputes over $B[..=i_{\text{end}}]$, rewinding Bar Replay restores exact `status`, `trigger_count`, and `cooldown_remaining_bars`.
3. **Formula-Safe Audit Export:** `export_triggers_csv` filters `eval_base_timestamp <= cutoff` and passes every text column through `sanitize_csv_cell` (`=`, `+`, `-`, `@`, `|`, `\t`, `\r`, `\n` neutralized with `'`), while `export_triggers_json` emits deterministic RFC-8259 JSON with `\u00XX` control escaping and zero wall-clock fields.
