## 3. Pure Rust Mathematical Contracts (WASM-Safe `f64`/`i64`)

### 3.1. Compact Axis Value Formatting (`K` / `M` / `B` / `T`)
For finite $v \in \mathbb{R}$ and optional grid step $s > 0$:
- $|v| < 10^{-9} \implies \text{"0"}$.
- Initial magnitude tier threshold $M \in \{10^{12} (\text{T}), 10^{9} (\text{B}), 10^{6} (\text{M}), 10^{3} (\text{K}), 1 (\text{""})\}$ selected at $0.99995 \times M$ pre-promotion boundaries, then formatted with trimmed trailing decimals and re-promoted once if rounded mantissa $\ge 1000.0$.

### 3.2. Session TPO Market Profile (`CBOT` 2-Bin Dual-Step Expansion)
For each venue-local session bucket $[i_{\text{start}}..i_{\text{end}}]$:
1. Initial Balance: $\text{IBH} = \max_{i \in [i_{\text{start}}, \min(i_{\text{start}} + k_{\text{ib}} - 1, i_{\text{end}})]} H_i$, $\text{IBL} = \min L_i$.
2. Price bins $b \in \{0..B-1\}$ spanning $[L_{\text{ses}}, H_{\text{ses}}]$; each candle adds `+1` TPO to every overlapped row $b \in [b_{\text{low}}, b_{\text{high}}]$.
3. `POC`: $\arg\max_b (\text{tpo}_b, \text{vol}_b, -|p_b - \text{mid}_{\text{ses}}|)$.
4. 70% Value Area: start at `poc_bin`, greedily compare pair sums `tpo[up+1] + tpo[up+2]` vs `tpo[dn-1] + tpo[dn-2]` while `acc_tpo < va_target && (lo > 0 || hi + 1 < row_count)`, where `va_target = (total_tpo_count as f64) * cfg.value_area_pct * (1.0 - 1.0e-12)` (`cfg.value_area_pct = 0.70` default; `src/indicators/market_profile.rs:480-486`).
5. **Causal Naked POC (`DEF-001`):** scan forward strictly within $j \in (i_{\text{end}} + 1)..\text{candles.len()}$; stop at first $j$ where $L_j \le \text{POC} \le H_j$.

### 3.3. Causal Market Breadth & 4-Quadrant `RRG`
1. Slice every symbol feed AND the benchmark feed (`VNINDEX` / `SPY`) via `causal_closed_prefix_len(..., replay_causal_close_ts)` and strip any incomplete tail bucket.
2. For each symbol with aligned causal `RS_t` (`compute_relative_strength(..., sma_period = 10, replay_causal_close_ts)`), `EMA_10(RS)_t`, and `EMA_26(RS)_t` (`compute_causal_rrg_trajectory`, `src/scanner/breadth.rs:389-458`):
   $$\text{RS-Ratio}_t = 100 \cdot \left(1 + \frac{\text{fast}_t - \text{slow}_t}{|\text{slow}_t|}\right)$$
   where $\text{fast}_t = \text{EMA}_{10}(\text{RS})_t$ and $\text{slow}_t = \text{EMA}_{26}(\text{RS})_t$ for $|\text{slow}_t| > 10^{-12}$ (falling back during warmup to $\text{fast}_t = \text{EMA}_{10}(\text{RS})_t \text{ or } \text{RS}_t$ against the running mean of finite $\text{RS}$ values). Over $\text{EMA}_9(\text{RS-Ratio})_t$ (falling back during warmup to the running mean of finite $\text{RS-Ratio}$ values as $\text{baseline}_t$):
   $$\text{RS-Momentum}_t = 100 \cdot \left(1 + \frac{\text{RS-Ratio}_t - \text{baseline}_t}{100}\right)$$
   retaining the trailing up-to-`4` valid `(rs_ratio, rs_momentum)` points (`pts[pts.len().saturating_sub(4)..]`, or `(100.0, 100.0)` fallback if empty).
3. Quadrant classification centered at `(100, 100)`: `Leading` ($\ge 100, \ge 100$), `Weakening` ($\ge 100, < 100$), `Lagging` ($< 100, < 100$), `Improving` ($< 100, \ge 100$).
4. `AT09` Aggregate-Before-Ratio Money Flow (`AT05` guard): $\text{VWBFP} = \text{clamp}\!\left(100 \cdot \frac{\sum_i \text{BuyValue}_i}{\sum_i \text{TradingValue}_i}, 0.0, 100.0\right)$ when finite $\sum_i \text{TradingValue}_i > 0$, defaulting to neutral `50.0` (`f64`) otherwise.
