### 3.1. Orthogonal 4-Family Causal Confluence & Quality Gate (`src/scanner/catalog.rs`)
Let $S = \{c_i \mid c_i.\text{timestamp} \le \tau_{\text{cutoff}}\}$ be the causal candle prefix, and let the evaluated index be $t^* = |S| - 2$ when `exclude_incomplete_tail_signal` is active (`tail_bar_excluded = true`) or $t^* = |S| - 1$ otherwise.
- **Quality Invariant:** Every `SignalEvaluation` enforces `quality != SignalQuality::Valid` $\implies$ `bool_value = None` $\land$ `float_value = None`.
- **Composite Health Score ($t^* \ge 50$):** Four bounded family scores $f_{\text{trend}}, f_{\text{mom}}, f_{\text{shift}}, f_{\text{flow}} \in [-1, +1]$ combine under profile weights $(w_1, w_2, w_3, w_4) \in \{(0.35, 0.25, 0.20, 0.20),\; (0.50, 0.20, 0.15, 0.15)\}$:
  $$H(t^*) = 100 \cdot \text{clamp}\!\left(w_1 f_{\text{trend}}(t^*) + w_2 f_{\text{mom}}(t^*) + w_3 f_{\text{shift}}(t^*) + w_4 f_{\text{flow}}(t^*),\; -1.0,\; 1.0\right)$$
  where $f_{\text{trend}}$ uses `Close`, `EMA(20)`, `EMA(50)`, 5-bar `EMA(20)` slope, and causal Ichimoku Kumo (`Senkou A/B` displaced from $t^* - 26$), and $f_{\text{flow}}$ uses prior-window `RVOL(20)` over $S[t^*-20 .. t^*)$ signed by close-location value $\frac{(C - L) - (H - C)}{H - L}$ with explicit `"bb_absent_neutral"` and `OHLCV_PROXY` disclosure.

### 3.3. Deterministic `SplitMix64` Bootstrap Envelopes (`src/backtest/monte_carlo.rs`)
Given initial capital $E_0 > 0$ and chronologically closed causal trades $\{T_1, \dots, T_N\}$ ($T_k.\text{exit\_timestamp} \le \tau_{\text{cutoff}}$):
1. **Sequential Pre-Trade Equity Return Extraction:** With $E_{k-1} = E_0 + \sum_{j=1}^{k-1} T_j.\text{net\_pnl}$, for each trade with $E_{k-1} > \varepsilon$:
   $$r_k = \text{clamp}\!\left(\frac{T_k.\text{net\_pnl}}{E_{k-1}},\; -1.0,\; 100.0\right)$$
2. **Unbiased Resampling & Bankruptcy Absorption:** Using `SplitMix64` state $z_{m+1}$ and 128-bit Lemire index $u = \lfloor (z \cdot K) / 2^{64} \rfloor \in \{0, \dots, K-1\}$ across $S \in [100, 5000]$ paths of horizon $H$:
   $$E^{(s)}_{h} = \begin{cases} 0 & \text{if } E^{(s)}_{h-1} \le 10^{-9} \lor E^{(s)}_{h-1}(1 + r_{u_{s,h}}) \le 10^{-9} \\ E^{(s)}_{h-1}(1 + r_{u_{s,h}}) & \text{otherwise} \end{cases}$$
   $$D^{(s)} = \max_{1 \le h \le H} \frac{P^{(s)}_h - E^{(s)}_h}{P^{(s)}_h} \times 100\%, \quad P^{(s)}_h = \max_{0 \le j \le h} E^{(s)}_j$$
3. **Order-Statistic Monotonicity:** Sorting $\{D^{(s)}\}_{s=1}^S$ ascending yields $\text{VaR}_\alpha = Q_\alpha(D)$ and $\text{CVaR}_\alpha = \frac{1}{|\mathcal{T}_\alpha|} \sum_{d \in \mathcal{T}_\alpha} d$ for $\alpha \in \{0.95, 0.99\}$, guaranteeing $0 \le D_{p50} \le \text{VaR}_{95} \le \text{VaR}_{99} \le 100$ and $\text{VaR}_\alpha \le \text{CVaR}_\alpha$, while equity fan checkpoints satisfy $Q_{0.05}(E_t) \le Q_{0.25}(E_t) \le Q_{0.50}(E_t) \le Q_{0.75}(E_t) \le Q_{0.95}(E_t)$ for every bar $t$.
