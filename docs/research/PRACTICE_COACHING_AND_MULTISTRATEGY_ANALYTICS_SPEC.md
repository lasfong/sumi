## 3. Pure Rust Mathematical & Causal Contracts (WASM-Safe `f64`/`i64`/`u64`)

### 3.1. Tamper-Proof Initial SL Adherence & Causal `PracticeDecisionNote` (`A1` + `A2`)
- **Entry-Time Stop-Loss Immutability:** On `None -> Some(Position)` transition (including the second leg of an opposite-side position flip), `Position` records `entry_stop_loss = clean_sl` and `had_initial_sl_at_open = clean_sl.is_some()`. Neither `apply_update_brackets_internal` nor same-side scale-in fills may mutate `had_initial_sl_at_open` or `entry_stop_loss`.
- **Session SL Adherence Formula:** Across $M = |\text{closed\_trades}| + \mathbb{I}(\text{open\_position.is\_some()})$ total opened round-trip positions in the session, let $M_{\text{sl}}$ be the count with `had_initial_sl_at_open == true`:
  $$\text{sl\_adherence\_pct} = \begin{cases} \text{None} & \text{if } M = 0 \\ \text{Some}\!\left(\dfrac{100 \cdot M_{\text{sl}}}{M}\right) & \text{if } M \ge 1 \end{cases}$$
- **Causal Decision Notes (`DEF-001`):** Each `PracticeDecisionNote` carries `(id, symbol, timeframe, base_bar_index, bar_timestamp, mark_price, action, setup, mistake, conviction, checklist, note)` and satisfies:
  $$\text{is\_causally\_visible}(n) \iff \neg \text{replay\_active} \lor \left(n.\text{base\_bar\_index} \le i_{\text{cursor}} \land n.\text{bar\_timestamp} \le t_{\text{cutoff}}\right)$$

### 3.2. UTC-Aligned `0%` Multi-Strategy Equity Overlay (`A4`)
Given causal chart slice $C = [c_0, \dots, c_{N-1}]$ at timeframe $\Delta$ (`bar_span` $= \max(1, \Delta) - 1$) and optional `replay_causal_close_timestamp` $\tau_{\text{cut}}$:
1. Each preset $p \in \text{StrategyPresetKind::ALL}$ (`7` presets) executes causally via `run_backtest_with_options`. For bar $i$ with causal close $t_i^{\text{end}} = \min(c_i.\text{ts} + \text{bar\_span},\; c_{i+1}.\text{ts} - 1,\; \tau_{\text{cut}})$, its rebased return is:
   $$R_p[i] = \left(\frac{E_p(t_i^{\text{end}})}{E_0} - 1\right) \times 100\%$$
2. `Asset Buy & Hold` starts at $b_0 = c_0.\text{close}$ (`0.00%` at $i = 0$): $R_{\text{BH}}[i] = ((c_i.\text{close} / b_0) - 1) \times 100\%$.
3. `Benchmark` (`VNINDEX` for Vietnam feeds, `SPY` for US/global feeds) resolves overlapping candles $B$ (`resolve_benchmark_series_for_window`), filters causally by $b.\text{ts} + \text{span}_B \le t_i^{\text{end}}$, anchors $B_{\text{ref}}$ at the first causally matched bar, and projects $R_{\text{BM}}[i] = ((B_{\text{close}}(t_i^{\text{end}}) / B_{\text{ref}}) - 1) \times 100\%$.
4. Every curve builds a `SeriesBlockIndex` (`BLOCK_SIZE = 64`) for $O(1)$ viewport autoscale and conflated polyline rendering on `100k`-bar series.

### 3.3. Outlier Impact, Drawdown Episodes, Causal Entry-Regime Slices, Multi-Phase Batch & `RunManifest` (`A5`)
- **Outlier Impact (`N = |trades|`):**
  - Winners $W = \{t \mid t.\text{net\_pnl} > \epsilon\}$ sorted descending, $G_+ = \sum_{t \in W} t.\text{net\_pnl}$; `top_3_winners_share_of_gross_profit_pct` $= \text{Some}(100 \cdot \sum_{j=1}^{\min(3,|W|)} W_j / G_+)$ iff $G_+ > 10^{-9}$, else `None`.
  - Losers $L = \{t \mid t.\text{net\_pnl} < -\epsilon\}$ sorted ascending (most negative first), $G_- = \sum_{t \in L} |t.\text{net\_pnl}|$; `top_3_losers_share_of_gross_loss_pct` $= \text{Some}(100 \cdot \sum_{j=1}^{\min(3,|L|)} |L_j| / G_-)$ iff $G_- > 10^{-9}$, else `None`.
  - Symmetric `10%` Trimmed Expectancy: for $N < 3$, `None`; for $N \ge 3$, sort all $N$ trade `net_pnl` values ascending, set $k = \max(1, \lfloor N / 10 \rfloor)$ (guaranteed $2k < N$ for all $N \ge 3$), and average `sorted[k .. N - k]`.
- **Discrete Underwater `DrawdownPeriod`s:** Scan `equity_curve` tracking running `(peak_equity, peak_bar_index, peak_timestamp)`. Entering `pt.equity < peak_equity` opens an episode tracking `(trough_equity, trough_bar_index, trough_timestamp, max_dd_abs, max_dd_pct)`; reaching `pt.equity >= peak_equity` closes the episode with `recovery_timestamp = Some(pt.timestamp)` and `duration_bars = pt.bar_index - peak_bar_index`; an unrecovered episode at `N - 1` emits `recovery_timestamp = None`.
- **Causal Entry-Signal `MarketRegime` Attribution (`DEF-001`):** Precompute `regimes = compute_regime_series(causal_candles)` in $O(N)$. Because backtest orders signal at `Close[T]` and fill at `Open[T + 1]` (`T + 1 == trade.entry_bar_index`), each `trade` is attributed to `signal_bar = trade.entry_bar_index.saturating_sub(1)` (`regimes[signal_bar]`), **never** `exit_bar_index` or `Close[entry_bar_index]`.
- **Deterministic `RunManifest`:** Hashes `(schema_version, symbol, timeframe, bar_count, first_timestamp, last_timestamp, replay_cutoff_timestamp, incomplete_tail_bar, normalized_config_ron, num_trades, final_equity_bits)` via `SplitMix64` (`0` wall-clock timestamps).
