## 3. Pure Rust Mathematical & Microstructure Contracts (WASM-Safe `f64`/`i64`)

### 3.1. Uniform Axis Edge Clearance & Scale-Step Decimal Formatting (`src/viewport/price_scale.rs`)
For pane height $H \in \mathbb{R}$:
$$\text{edge\_pad}(H) = \begin{cases} 0.5 & \text{if } \neg\text{finite}(H) \lor H \le 4.0 \\ 11.5 & \text{if } H \ge 48.0 \\ \min\!\big(\text{clamp}(0.24 H,\; 1.0,\; 11.5),\; 0.45 H\big) & \text{otherwise} \end{cases}$$

For visible raw price bounds $[p_{\min}, p_{\max}]$ with scale magnitude $M = \max(|p_{\min}|, |p_{\max}|)$ and step $s$:
$$d_{\min}(M) = \begin{cases} 2 & \text{if } \neg\text{finite}(M) \lor M \ge 1.0 \lor M = 0.0 \\ 4 & \text{if } M \ge 0.01 \\ 6 & \text{otherwise} \end{cases}$$
$$\text{decimals}(p_{\min}, p_{\max}, s) = \text{clamp}\!\left(\min\left\{d \in [\max(0, \lfloor -\log_{10} s \rfloor)..8] \;\middle|\; |10^d s - \text{round}(10^d s)| \le 10^{-6}\right\},\; d_{\min}(M),\; 8\right)$$
When `Logarithmic` mode emits multi-decade candidates (`step_hint == None`), `effective_step` is inferred from the minimum positive adjacent gap $\min_i (c_{i+1} - c_i)$ so every tick on the axis shares a single fixed decimal count.

### 3.2. Causal `OHLCV_SYNTH_DOM_PROXY` Price Ladder & VN Exchange Rules (`src/trading/ladder.rs`)
1. **Validation & Causal Cutoff (`DEF-001`):** `compute_causal_dom_ladder` rejects `half_rows == 0` or `lookback_bars == 0` with `DomLadderError::InvalidConfig`, and filters strictly to candles satisfying `c.timestamp <= causal_cutoff_ts` (when `Some(cutoff)` is active in Bar Replay or incomplete-tail gating). Future bars after `causal_cutoff_ts` have **zero** influence on mark price, prior-session `REF` close, `CEIL`/`FLOOR` band, footprint `Bid×Ask` volume, or synthetic liquidity depth.
2. **Single-Anchor Unit Resolution & Exact Tier-Crossing Grid:**
   - Resolve `resolved_unit: ResolvedVnPriceUnit = config.vn_unit.resolve_for_venue(config.venue, unit_anchor)` **once** per snapshot using `unit_anchor = ref_price.unwrap_or(mark_price)`.
   - Quantize `center_price = snap_to_nearest_tick(raw_center, config.venue, resolved_unit)` **before** stepping `half_rows` ticks upward via `step_one_tick_above` and `half_rows` ticks downward via `step_one_tick_below` (`total_rows = (2 * half_rows + 1)` clamped to `3..=61`, default `21`). On `ExchangeVenue::Hose` (`ThousandVnd`), crossing `50.00` steps `49.90, 49.95, 50.00, 50.10, 50.20` with zero skipped boundary ticks.
3. **Venue-Local Prior Session Reference & Daily Price Band:**
   - `infer_causal_prior_session_close(candles, venue, causal_cutoff_ts)` buckets bar timestamps by `local_day = c.timestamp.saturating_add(venue.utc_offset_seconds()).div_euclid(86_400)` so VN (`UTC+7`) and US (`UTC-5`) intraday sessions resolve the true prior local trading day's final close as `reference_price`, falling back to the earliest causal bar's `open` when only one local trading day exists.
   - `compute_daily_price_band_with_resolved_unit(config.venue, ref_price, resolved_unit)` yields `DailyPriceBand` (`HOSE ±7%`, `HNX ±10%`, `UPCOM ±15%`, `VN30F ±7%`), tagging rows as `AboveCeiling`, `Ceiling`, `Reference`, `Floor`, `BelowFloor`, or `Normal`.
4. **Causal `CLV` Footprint & Synthetic Resting Depth (`OHLCV_SYNTH_DOM_PROXY`):**
   - Over the trailing `lookback_bars` (`1..=500`, default `120`) causal bars, each bar splits `volume` into `buy_v = volume * ((close - low) / (high - low)).clamp(0.0, 1.0)` (`0.5 * volume` doji fallback when `high <= low`) and `sell_v = (volume - buy_v).max(0.0)`, distributed conservatively across intersecting ladder rows via normalized Gaussian typical-price proximity weights `typical_row_weight(row_price, row_tick, bar_typ, span)`.
   - Rows strictly above `mark_price` inside `[floor, ceiling]` receive lot-snapped synthetic resting `synth_ask_depth`; rows strictly below `mark_price` inside `[floor, ceiling]` receive `synth_bid_depth`, weighted by piecewise exchange tick distance `exact_tick_distance(row.price, snapped_mark, venue, resolved_unit)` ($0.35 + 0.65 e^{-d/6}$) plus historical node affinity $0.5 + 0.5 (V_{\text{row}} / V_{\max})$, snapped via `floor_to_board_lot(config.venue, ...).max(config.venue.board_lot())`. Out-of-band rows (`AboveCeiling` / `BelowFloor`) carry `0.0` resting depth.
5. **Click-to-Stage Order Selection, Band Validation, Slippage Brackets & Short Guard (`stage_ladder_order`, `compute_quick_market_brackets`):**
   - Snap clicked price via `entry = snap_to_nearest_tick(clicked_price, venue, resolved_unit)`. Reject `NonFiniteInput` or `InvalidQuantity` (`snapped_qty < venue.board_lot()`).
   - If `DailyPriceBand` exists and `entry < band.floor_price - band_tol || entry > band.ceiling_price + band_tol`, reject `OutsideDailyPriceBand { price, floor, ceiling, decimals }` on the **entry** price with exact venue ladder decimals (`decimals_for_venue_ladder_tick`).
   - **Short-Selling Guard:** When `side == OrderSide::Sell`, compute `closable_long` from an open `PositionSide::Long` (`0.0` otherwise). If `snapped_qty > closable_long + 1e-7` and `(!venue.allows_short() || !allow_account_short)`, reject `ShortNotAllowedByVenue` (blocking naked shorts and excess long-to-short flips on `HOSE`/`HNX`/`UPCOM` while allowing closing an existing long position).
   - **Order Kind Selection (`tick_tol = 0.25 * tick_at_entry`):**
     - `OrderSide::Buy`: `entry <= mark_price + tick_tol` -> `OrderKind::Limit { limit_price: entry }`; else `OrderKind::Stop { stop_price: entry }`.
     - `OrderSide::Sell`: `entry >= mark_price - tick_tol` -> `OrderKind::Limit { limit_price: entry }`; else `OrderKind::Stop { stop_price: entry }`.
   - **Tick-Stepped Brackets (`SL` / `TP`):** Limit/Stop bracket ticks step via `step_one_tick_below` / `step_one_tick_above` without clamping to today's daily band; quick `Market` bracket orders use `compute_quick_market_brackets(...)` anchored around `apply_slippage(mark_price, side, slippage_bps)` so tight `1`-tick `TP`/`SL` intervals remain valid under non-zero slippage.
