## 2. Six Legacy Defects Rectified in Pure Rust

1. **Kumo Twist Bowtie Self-Intersection & Alpha Seam Overhead (`IchimokuCloudPlugin.ts:42–79`, `REA-R12-05`):**
   - Legacy TS rendered each consecutive pair `(prev, curr)` as a single unsplit polygon painted immediately with `ctx.fill()` using `currA > currB ? upColor : downColor`. Whenever `Senkou Span A` crossed `Senkou Span B`, the quad self-intersected like a bowtie and colored both halves identically. Separate per-bar fills also introduced translucent vertical alpha seams and $O(N)$ Canvas state switches.
   - **Rust Fix (`src/chart.rs` `paint_ichimoku_cloud`):** Emits a single batched `egui::Mesh` behind candlesticks. Whenever `(a0 - b0)` and `(a1 - b1)` have opposite strict signs, computes exact linear intersection $t = \frac{d_0}{d_0 - d_1} \in (0, 1)$, $(x_{\text{mid}}, p_{\text{mid}})$, and splits the interval into two clean disjoint triangles (`bull` vs `bear` fills) meeting flush at $(x_{\text{mid}}, y_{\text{mid}})$ — eliminating bowties and alpha seams completely. At macro zoom (`conflation_factor > 1`), steps by conflated buckets while retaining exact crossover splits.
2. **Replay Stripping Future Cloud `+D` & Unbounded `offset < 0` Lookahead (`indicator_engine.py:36–38, 295–307`, `replay.py:201–236`):**
   - Legacy `IndicatorEngine` and `/replay` truncated everything beyond `max_visible_dt`, wiping out the $+26$ forward-projected Kumo bars even though $\text{Senkou A}[i + D]$ and $\text{Senkou B}[i + D]$ are computed strictly from historical OHLCV $\le i$. Meanwhile, `COMMON_PARAMS.offset` lacked `minimum = 0`, allowing `offset = -5` lookahead leaks, and `IndicatorRenderRegistry.ts` required all 5 columns simultaneously while ignoring custom `senkou_b` periods.
   - **Rust Fix (`src/indicators/ichimoku.rs`):** Computes $O(N)$ dual-monotonic-deque Donchian midpoints (`tenkan`, `kijun`, `senkou_b_raw`), projects `senkou_a` and `senkou_b` strictly forward into length `N + D` (zero future close leakage), and strictly masks `chikou[k] = None` for all `k >= N.saturating_sub(D)` (`DEF-001` future-close isolation).

## 4. Mathematical & Security Contracts (`DEF-001`, Pure `f64`/`i64`, `wasm32`-Safe)

### 4.1 Ichimoku Kinko Hyo (`src/indicators/ichimoku.rs`)
- **Rolling Donchian Midpoints ($O(N)$ dual monotonic `VecDeque<usize>`):**
  $$\text{Mid}_P[i] = \text{lo}_P[i] + 0.5 \cdot (\text{hi}_P[i] - \text{lo}_P[i]), \quad i \ge P - 1$$
  Recovers deterministically after corrupted/non-finite or inverted (`high < low`) candles via `finite_run` reset.
- **Line Definitions (`(tenkan, kijun, senkou_b, displacement) = (9, 26, 52, 26)` default, clamped `1..=500` & `0..=250`):**
  - `tenkan[i] = Mid_{tenkan_period}[i]` for $i \in [0, N)$
  - `kijun[i] = Mid_{kijun_period}[i]` for $i \in [0, N)$
  - `senkou_a[i + D] = 0.5 * (tenkan[i] + kijun[i])` (`N > 0 => len = N + D`, strictly causal from bars $\le N - 1$)
  - `senkou_b[i + D] = Mid_{senkou_b_period}[i]` (`N > 0 => len = N + D`, strictly causal from bars $\le N - 1$)
  - `chikou[k] = close[k + D]` **strictly iff** `k + D < N`; **MUST be `None`** for `k >= N.saturating_sub(D)` (`DEF-001`).

### 4.2 Cumulative Volume Delta (`src/indicators/cvd.rs`)
- **Explicit Method Label:** `OHLCV_PROXY` (derived strictly from OHLCV candles via `intrabar_buy_fraction`; returns `Some(0.0)` when `volume == 0.0` and `None` on non-finite/negative/inverted bars).
- **Conservation Identity:** $V_{\text{buy}} = V \cdot f_{\text{buy}}(O, H, L, C)$, $V_{\text{sell}} = V - V_{\text{buy}}$, $\Delta_i = V_{\text{buy}} - V_{\text{sell}}$, $V_{\text{buy}} + V_{\text{sell}} = V$.
- **Regimes (`CvdResetMode`):**
  - `Session`: resets running sum $\text{CVD} = 0$ and SMA accumulator whenever `session_bucket_key(timestamp, timeframe, utc_offset_seconds)` transitions (`UTC+7` HOSE/VN30F intraday midnight, `1D` calendar month, `1W` calendar year).
  - `Cumulative`: continuous running sum across `[0..N)`.
  - `cvd_sma[i]`: rolling mean over `sma_period` (default `9`), computed strictly within each active session segment (`64`-bar running sum reseed for numerical stability).
