# Documentation-directory agent rules

The repository-level `../AGENTS.md` is authoritative. When working under `docs/`:

- Keep V3 canonical documents consistent with `docs/INDEX.md`.
- Treat V2 and pre-V2 documents as historical evidence; do not rewrite them to imply V3 completion.
- Record architecture changes as explicit ADRs and delivery work as ExecPlans following `../PLANS.md`.
- Do not weaken acceptance criteria in the same batch that implements the affected feature without reviewer approval.
