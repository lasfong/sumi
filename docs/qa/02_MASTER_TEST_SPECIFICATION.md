# 02. Bộ Kịch Bản Kiểm Thử Tổng Thể & Ma Trận Test Case — Sumi Supercharts (`v2.1.0`)

> **Tổng số Test Case:** **113 Test Cases** phủ kín **11 Phân hệ** (`TC-DATA`..`TC-PERF` + `TC-MTF-REPLAY` hành trình liên phân hệ thực chiến), gồm đầy đủ Happy Path, Edge Cases, Negative Tests và Stress/Soak Benchmarks.  
> **Nguyên tắc thực thi bắt buộc:** 100% chạy trên **ứng dụng thật & backend Rust thật** (**Tầng A**: `/Applications/Sumi Supercharts.app` native macOS; **Tầng B**: Real-Backend Bridge nối trực tiếp tới toàn bộ 51 Tauri commands + `AppState` + `sumi_market.db` 958.359 nến + `sumi_workspace.db` + `tradingview-rs`). **Cấm tuyệt đối `webFallback.ts`.**
