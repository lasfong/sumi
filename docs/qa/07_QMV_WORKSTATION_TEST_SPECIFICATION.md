## 1. Kiến Trúc Kiểm Thử Hai Tầng Thực Tế (Dual-Layer Real-App QA)

Để kiểm tra trọn vẹn cả tiến trình Desktop macOS gốc lẫn từng pixel tương tác trên Canvas/UI mà không vi phạm giới hạn quyền hệ điều hành macOS TCC (`Screen Recording` / `Accessibility`):

1. **Tầng A — Ứng Dụng Native macOS (`/Applications/Sumi Supercharts.app`) & CSDL SQLite Thực Tế:**
   - Kiểm tra chữ ký số (`codesign -dv`), khởi chạy lạnh/ấm (`open -a "/Applications/Sumi Supercharts.app"`), kiểm tra PID, file descriptors (`lsof`), chế độ `WAL` của `sumi_market.db` và `sumi_workspace.db`, mức tiêu thụ RAM/CPU, và vòng đời Đóng/Mở lại ứng dụng.
   - **Quy tắc an toàn dữ liệu:** Trước khi chạy thử nghiệm có ghi dữ liệu lên `~/Library/Application Support/com.sumi.supercharts/sumi_workspace.db`, **bắt buộc sao lưu bản gốc ra thư mục tạm** và khôi phục nguyên trạng sau khi kiểm thử xong. Tuyệt đối không xóa/ghi đè hỏng `sumi_market.db` thật.

2. **Tầng B — Cầu Nối E2E Lõi Rust Thật (`Real-Backend Tauri IPC Bridge`) + Trình Duyệt Tương Tác Trực Quan (`1440×900` & `1280×800`, 2× HiDPI):**
   - Tạo một tiện ích cầu nối nhỏ nằm **hoàn toàn trong thư mục tạm `<Artifact Directory Path>/scratch/qa_qmv_bridge/`** (không chạm vào bất kỳ tệp nào của repo `/Users/mizuhara/workspace/sumi`):
     - Khởi tạo trực tiếp `sumi_desktop_lib::state::AppState::initialize(copy_of_market_db, isolated_workspace_db)` (dùng `tauri = { version = "2", features = ["test"] }` với `tauri::test::mock_builder()` + `tauri::test::get_ipc_response` hoặc gọi trực tiếp các command handler trong `sumi_desktop_lib::commands::*`).
     - Phục vụ bản build chuẩn `ui/dist` qua HTTP cục bộ kèm script khởi tạo `window.__TAURI_INTERNALS__` chuyển tiếp toàn bộ `invoke(cmd, args)` thẳng xuống `AppState` Rust thật.
   - Điều khiển UI thực tế bằng Playwright / Browser Subagent / Chrome DevTools trên cả 2 kích thước màn hình (`1440×900` chuẩn Desktop và `1280×800` chuẩn MacBook 13"), chụp ảnh bằng chứng PNG độ nét cao lưu vào `/Users/mizuhara/workspace/sumi/docs/qa/evidence_qmv/`, và **dùng `read_file` mở xem trực tiếp từng bức ảnh PNG** để soi lỗi cắt chữ, tràn khung, chồng lấn nút, lệch màu hoặc lỗi vẽ Canvas.
